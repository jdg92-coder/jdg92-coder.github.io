# Repository Guide

## Project

This repository is a small, static personal website for Jamir Gomez, published as a GitHub Pages site. The current page is implemented directly in `index.html`.

## Visual direction

- Give pages and website features an old-style cartoon feel: playful hand-drawn shapes, expressive outlines, warm colors, and lively details where they suit the content.
- Keep text readable and layouts usable. Cartoon styling should not reduce contrast, accessibility, or mobile usability.
- Apply the visual direction consistently across the site while keeping each page clear and easy to navigate.

## Working in this repository

- Use only HTML, CSS, and vanilla JavaScript for website code. Do not introduce frameworks, libraries, server-side languages, or other programming languages.
- Keep the site simple and compatible with static hosting. There is currently no application framework, package manager, or build step.
- Make page changes in the existing HTML unless the requested feature calls for separate CSS, JavaScript, or assets.
- Preserve semantic, accessible HTML and the existing responsive viewport setup.
- Keep documentation in `README.md` accurate when project setup or behavior changes.
- Limit changes to the repository root and files relevant to the request. Do not modify nested directories that may contain separate repositories unless asked.
- Do not add dependencies or build tooling. Implement requested behavior using HTML, CSS, and vanilla JavaScript.

## Validation

- For HTML changes, inspect the resulting `index.html` and, when browser preview is available, check that the page renders at desktop and mobile widths.
- There are no configured automated tests or build commands at present. Do not invent a test or build workflow unless the project needs one.
